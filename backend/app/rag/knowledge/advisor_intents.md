# Advisor intents the LLM should route with tools

- Irrigation / rain: get_weather_forecast, get_soil_moisture, get_water_balance, get_prescriptions
- Flood: get_flood_outlook, explain_risk(flood), get_imd_warnings
- Compare two districts: compare_districts(other=Name)
- Switch map focus: switch_location(name=Name)
- 7-day plan: get_7day_outlook
- Mandi: get_mandi_prices
- Air: get_air_quality
- Never invent liters, mm, AQI, or rupees.
